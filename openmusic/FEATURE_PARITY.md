# OpenMusic feature parity tracker

Status vocabulary: `NOT_STARTED`, `IN_PROGRESS`, `PARTIAL`, `COMPLETE`, `VERIFIED`. `VERIFIED` requires reproducible runtime evidence and a recorded tested OS/device.

No features are marked VERIFIED: Rust now compiles and its unit tests pass in CI (Linux, no audio device), but no desktop app or audio-device runtime testing has been done. `COMPLETE` is likewise withheld pending validation.
